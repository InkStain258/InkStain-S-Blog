# 第一节 文学的价值

## 文学的价值和价值观

- 价值:是一个揭示客观事物满足人和社会需要的关系范畴。

- 价值观:人们关于价值本质的认识以及对人和事物的评价标准、评价原则和评价方法的观点的体系。

### 文学价值及其生成

- 文学价值是文学作品满足人和社会需要的属性。
- 1. 文学价值的创造:作家的创造是文学价值的基础。

     - 文学价值植根于所描绘的社会生活。例析毛泽东《七律·长征》；豪放词与婉约词；花间词、齐梁体。
     - 文学价值之生成还受制于作家对社会生活的认识和道德评价以及作家的审美创造力。
  2. <span data-type="text" style="background-color: var(--b3-card-info-background); color: var(--b3-card-info-color);">文学价值的实现：读者的阅读接受使文学价值成为现实。不同阶段、不同水平的阅读接受影响文学价值的实现程度。</span>

### 文学价值与文学评价

- 文学价值既具有客观的和相对不变的特性，又具有随接受者及其阅读语境变化而发生变化的特性
- 不同群体、不同阶段（60年代以来的文学作品主人公）、不同水平的、不同的思想立场有不同的文学评价。**文学评价影响文学价值的实现程度和对文学价值之性质、大小的不同认识。**
- **如面对《红楼梦》--索隐派：清代信史；考证派：曹雪芹自传；王国维：真正的悲剧（自形成自解脱）；毛泽东：旧社会的百科全书。** 

  - 关于红楼梦最重要的章节的认识（第四章（护身符-社会阶级性与阶级斗争）\第五章（太虚幻境-总纲）之分）
  - 《安娜·卡列尼娜》：安娜与司机的邂逅，下车后突然发现丈夫的外貌丑陋（评判标准起了变化）
  - 叶燮认为古今诗人只有三个:杜甫、韩愈和苏轼；王士祯则认
    为可称为仙才的只有三人:曹植、李白和苏轼。赵翼则称李白、杜甫、苏轼为古今三大诗人。赵翼评东坡诗:“才思横溢，触处生春，胸中书卷繁富，又足以供其左旋右抽，无不如志。其尤不可及者，天生健笔一枝，爽如哀梨，快如并剪，有必达之隐，无难显之情。此所以继李、杜后为一大家也。”

## 文化价值的多样性和主导价值

> 文学金字塔：通俗文学——纯文学——思想性文学（讲对了不一定是悟了，悟了才是真正的懂了）

- **价值内部是矛盾的（《明事儿》看是好看的，但是记不住多少，没有提供真正内容上的创新-汪国真）**

> 精神上的的产品一定要创新，否则很难在长期的历史时段内掀起波澜

### 文学价值的多样性和可变性

- **文学价值本身是多样的。文学作品在读者接受中显示出多种价值。文学价值**
- 多样性的原因：

  - 作家的个性和水平是多样的。社会生活本身是多样的。

> - 文学价值多样性的体现：
>
>   - 从内涵讲：①人文价值；②伦理价值；③3审美价值；④文化价值；⑤交往价值；⑥科学价值；⑦商业价值等。
>   - 从价值意义和效果言而：①正面价值与负面价值；② 积极价值与消极价值；③短暂价值与长久价值；④现实价值与未来价值；⑤显在价值和潜在价值。
>   - 从价值意义和效果言而：①正面价值与负面价值；② 积极价值与消极价值；③短暂价值与长久价值；④现实价值与未来价值；⑤显在价值和潜在价值。

- 文学价值的可变性

  - 文学价值评判尺度随时代变迁和读者审美需求变化而发生变化。同一部文学作品的价值在不同时代往往呈现出明显的多样性、变化性和差异性。
  - 陶渊明-一钟嵘《诗品》评之为“中品”，唐宋被拔高。
  - 费多《范妮》与福楼拜《包法利夫人》

### 文学主导价值（文以载道）

- 主导价值指在文学作品多样性的价值中占主导地位的价值。（不同时代的主导价值是不同的）
- 倡导正确的文学价值取向（社会主义核心价值）。把弘扬主旋律与提倡多样化统一起来。 **（正确处理社会主义价值和其他价值的关系-从理论上来说既要歌颂光明也要记述黑暗-文学不在内容，在于态度-分析批判丑恶而不是提倡丑恶）**
- 遵循文学自身规律。
- 注意避免文学价值取向的失衡与沉沦。

## 文学的真善美

### 文学价值的真善美

- 真--认识价值--通过合乎艺术规律的方式，呈现社会真实状况、人生真正面目、作家真诚体验。 **（现象真实和本质真实——父子案）（文学作品是把现象真是真实和本质真实相结合——本体的真实）**  **（通过艺术手段表现的本体真实——艺术真实（可以虚构））** 

  - <span data-type="text" style="background-color: var(--b3-card-info-background); color: var(--b3-card-info-color);">艺术真实不同于生活真实，生活真实又不同于生活现象（落脚到本条真实，艺术真实需要符合但是不用处处受制）</span>
  - 卡夫卡《变形计》；专业的选择\老人吃饭的实例（人具有经济能力才有话语权）
- 善--<span data-type="text" style="background-color: var(--b3-card-info-background);">道德价值(思想价值)--反映对生命之尊重</span>，对人性健康发展之追求，对人类和平幸福之向往。

  - 有人指出，所谓善是指给绝大多数人带来最大幸福的事物；另一些人认为，善是指有助于人类向拥有更大的力量和智慧进化的东西；还有一些人坚持认为，善是根据上帝的指令行事。
- 美--审美价值--有真善之内涵，有充沛之情感，有形象之言说，有创造性形式与技巧。

  - **满足情感需求和激荡心灵的属性——美（精神愉悦）（美是一个二元论的东西——客观的美+主观的精神满足）** （美与人的主观判断是相勾连的）
- 不同时代、阶级和流派对文学的真善美的肉体内涵的理解是不同的。

### 文学需要真善美的统一

- 真善美本质上是统一。文学要实现三者的统一。在好的作品中，真善美三者缺一不可。
- 真善美各自独立，但又相辅相成。（可以独立的描述某一方面）

  - 《汤姆叔叔的小屋》：真善，艺术性不强，表达了民族平等的现实需求
  - **文学作品可以凭借三者其一求得成功，但是真正有着历史影响的文达作品需要寻求三者的统一**
- 宋诗比不上唐诗，一个重要原因是喜欢说理（散文入诗），形象性不够，也就是说，在艺美这个方面有所欠缺。

### 对文学真善美价值的评定

- 不同的人有不同的价值观，对真善美的评定也不一致。
- 马克思主义强调人民本位，最终的评定者是人民。

  - **谁来代表人民（接受美学——文学作品的意义归于读者（谁为读者）——理想读者：价值理性、文学修养、审美体验（吊诡的））**
- **但人民是一个集合体，人民评定有个具体操作的过程。因此需要一个具体的评判标准。这个标准是辩证的，变化的，但在一定时期一定内又是稳定的。**
- 推荐阅读:赵炎秋:论文学形象意义的产生，《湖南农业大学学报》，2004年第4期。（作品是基础，读者是关键）（读者收到作品的限制-有一定的规定性-否则根本读不出某种特定的意义）

  - 裴多菲与李白：不能从《静夜思》读出追求自由

# 文学的功能

- 文学功能是文学的价值属性的实际反映和体现。
- 文学的功能是系统存在的。
- 文学功能：**认识功能、教育功能、审美功能、娱乐功能**、凝聚功能、益智功能、心理补偿功能等。

- 寓教于乐（贺拉斯）：

  - 教：教育与认识
  - 乐：审美与娱乐
  - “教”在“乐”之中

表面的的能力我们强于古人，但是理性和传统的能力却不一定强（技术的发展——本能的退化）

- 文学功能是相互联系、相互渗透的，具有整体性，体现在文学对人的情感、思想、欲望、理想、信念、道德、人格等等各个方面潜移默化的影响上。
- 优秀的文学作品对于人的全面发展，对于陶冶情操、鼓舞士气、提升境界等，有着不可替代的特殊作用

## 文学的认识功能

- 所谓文学的认识功能，是指文学作品能够扩大人的认知领域，具体包括对自然界、人类社会以及人自身的认识。也叫文学的认识作用。

- 包括两个方面:

  - 对客观方面的世界(自然与社会)的认识
  - <span data-type="text" style="color: var(--b3-font-color6);">对主观方面的人(他人和自己)的认识</span>

> 现代英国的一批杰出的小说家，他们在自己的卓越的、描写生动的书籍中向世界揭示的政治和社会真理，比一切职业政客、政治家和道德家加在一起所揭示的还要多。--马克思《马克思恩格斯全集》第10卷
>
> - [ ] 文学作品帮助我们认识社会

### 特点

1. 整体性认识：**整个**<span data-type="text" style="color: var(--b3-font-color8);">社会</span>

- 目的<span data-type="text" style="background-color: var(--b3-font-background6);">：</span>不在于探讨客观社会的科学知识，而是把握社会与人之间的关系（通过）

2. 文学作品可提高对人生的了解，增加对他人和自我的认识。

- 对莎士比亚来说，人的内心世界就是宇宙，他用天才而有力的笔画描绘出了这个宇宙。--俄国赫尔岑
- 李煜的创作前后期对比
- 《阿Q正传》的精神胜利法反映了人的特性（你评了教授，我养了身体，我们都有光明的未来）

## 文学的教育功能

> - **文学的教育功能或思想启迪功能是指(优秀的)文学作品能影响人的思想情感、净化人的心灵世界、增强人的生活勇气和信心。**
> - 文学的教育功能实质上就是一种通过提升和净化人的心灵直到某种具有现实影响力的**实践性**功能。
> - 文学的教育功能应该通过形象表现出来。**不应片面地强调教育功能**（与宣传不同，不是强调他人的接受）
> - 文学的教育功能与文学表现的内容应该是一致的<span data-type="text" style="background-color: var(--b3-card-warning-background); color: var(--b3-card-warning-color);">（美国电影《美丽心灵》：社会没有抛弃发疯者，最终恢复——写出《控制论》，通过这种人生经历歌颂一种人文关怀的精神和对于天才的尊重）（英国的诺贝尔文学家那保尔节约时间不想谈恋爱，喜欢嫖娼）（思考：我国的体系是否容得下疯子，嫖客和瘾君子,是选择包容还是无情的校正）</span>

- [ ] **这种教育功能更像是一种思想的启迪功能，使得思想更加开阔**
- [ ] <span data-type="text" style="color: var(--b3-font-color11);">要通过形象表现出来而不是讲道理直接告诉读者（马克思/恩格斯）</span>

  - [ ] 美国电影《月光男孩》：不要什么事情都给别人解决，要自己面对（看到电影就知道这个道理）

## 文学的审美功能

- 文学的审美功能，是指文学具有沟通文学活动中主体和客体，使人获得精神满足、情感愉悦和心灵净化，推动促进个性和才能的自由而全面发展的功能。审美功能逻辑上应可以包括后面所讲的娱乐功能。

> - [ ] 美：可以分为形式美和内容美（一片湛蓝的天空），内容美相对来说更加重要，这也是作品的立身之处（黑格尔）
> - [ ] “美”与“愉悦”是有区别的，前者是精神的满足，情感的愉悦和心灵的净化，后者只是单纯的快乐；前者需要包含形象性和心灵的满足，后者则是单纯的使人快乐和快感。（ **“为了学生的一切，为了一切的学生”显然不是美**）

- 作为一种语言艺术，文学主要是为了满足人的审美需求而存在与发展的，审美是文学最基本的功能。

> - 文学的审美功能对提高人的审美能力、丰富审美情趣、健全审美观念、升华精神境界、优化心理结构，发挥着十分重要的作用。
>
> - 审美功能具有历史性，是一个历史的范畴。
>
> - **文学各种功能是相互联系的，其中审美功能往往发挥着更基本、更核心的作用。其他功能通过审美功能挥作用。**

## 文学的娱乐功能

> - [ ] 文学的娱乐功能是指文学可以使人放松、消遣，给人带来身体快适、心情愉悦和精神自由的功能
>
> - [ ] **文学的娱乐功能也归入文学的审美功能范围内。把它单独划出来，是为了强调文学的愉悦、消遣、休闲的一面。审美功能强调精神满足，情感的激动、趣味的提升，严肃**
>
> - [ ] 娱乐功能强调快感、<span data-type="text" style="background-color: var(--b3-font-background4);">强</span>调生理满足(主要是想象性的)强调情感的愉悦，具有益智的特点，轻松

- **波特曼《娱乐至死》，我们需要娱乐，但是更需要审美**
- 在市场经济条件下的商业写作过度强调娱乐是绝不可取的

# 课后：

1. 何谓文学价值?文学价值是如何形成的?

文学价值是文学作品满足人和社会需要的属性。文学价值是作家和读者共同创造的，作 家的创造为文学价值提供了基础，读者的阅读接受使文学价值成为现实，因此文学价值的生 成包含两个重要环节，即文学价值的创造和文学价值的实现。在作品创造过程中,作家通过 对特定社会生活的艺术表现和评价，创造出一定的文学价值，而在作品传播和接受过程中， 读者又会根据自身情况对作品所表现的社会生活和作家的价值立场作出自己的评价,完成文 学价值的实现和再创造。文学价值是主客观统一的产物。从客观方面讲，文学的价值植根于 社会生活之中，是社会生活的集中表现与升华。从主观方面讲，文学价值还体现了艺术创造 自身的价值，其中既包含着作家对社会生活的认识和道德评价，也包含着作家的审美创造能力。文学价值的最终实现，是通过读者阅读和接受完成的。 

2. 什么是文学的认识功能和教育功能?

文学的认识功能，是指文学具有帮助人获得社会和人生知识、加深对人和社会理解的功 能。文学是社会、历史和人生的“百科全书" ，是人们获得间接知识的重要渠道。文学作为 一种艺术，不仅要再现生活，而且要高于生活。这就决定了文学的认识功能主要不在于探求 客观真理，而在于用艺术的形式实现对人与世界关系的把握。就作家方面来说，文学的认识 功能是通过作家在饱含情感的审美状态中进行文学创作来实现的。就读者方面来说，文学的 认识功能是通过读者的审美活动和获得的体验来实现的。 文学的教育功能是指文学作品具有影响思想情感、净化心灵世界、增强生活勇气和信心 的功能。广义地讲，文学的教育功能还包括文学具有政治的、社会的、伦理道德的启蒙和教 化功能在内。

文学的教育功能，实质上就是一种提升和净化人的心灵的功能。文学作品的任 何教育功能都必须通过文学的审美和娱乐功能去实现。文学的教育功能植根于文学与生活之 间的内在联系,主要有两方面：一方面在于文学反映和表现的对象本身具有教育意义,另一方 面在于文学对生活的反映和表现中渗透着作家爱憎臧否等思想感情倾向，自然形成对读者的 影响力和吸引力。 

3. 为什么说审美功能是文学最基本的功能?

 文学的审美功能，是指文学具有沟通文学活动中主体与客体的美感和情感需求，使人获 得精神对现实的超越，实现审美理想，推动促进个性和才能的自由而全面发展的功能。文学 审美功能是由文学的审美本性决定的。作为一种语言艺术，文学主要是为了满足人的审美需 求面存在和发展的，因此，从根本意义上讲，审美是文学最基本的功能。 

4. 试说明各种文学功能之间的关系。


文学的认识、教育、审美和娱乐功能的区分,只是从相对的意义上讲的，实际上它们并不 截然分离和单独发生作用。文学的各种功能是相互关联着的，有时候相互促进，有时候相互 冲突，有时则相互转化，共同构成了一个繁复的文学功能系统。其中，文学的审美功能往往 发挥更直接的作用。这可以从两个方面加以理解：一方面，文学的审美功能实际上是文学实 现其他功能的中介。因为无论是认识、教育功能，还是娱乐及其他的功能，在文学中都是通 过读者不同程度的审美体验才能得以实现的。文学提供给读者的不是抽象的概念系统，而是 动人的情感世界和具体的文学形象，这就内在地决定了读者从一开始就必须采取与之相适应 的美感接受方式。这样，审美就成了读者把握文学形象及思想内涵的主要通道，成了将作家 对人生的体验和感悟转化为读者精神财富的必经之途。 

另一方面，文学的审美功能又是以情感为中心的整体性概念，它是文学各种功能协调统一的 重要条件。文学的审美功能不仅表现在其他各种功能在内容上都渗透和蕴涵着情感体验的审 美因素，具有审美的意义与特征，而且表现在其他各项功能都统一于审美，都要以审美为旨归。
